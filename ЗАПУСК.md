# PagesMi - Визуальный конструктор страниц

## 🚀 Как запустить приложение

### Вариант 1: Использование npm (рекомендуется)

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Приложение откроется на http://localhost:3000
```

### Вариант 2: Сборка и запуск production версии

```bash
# Сборка проекта
npm run build

# Запуск production версии
npm start
```

## 📋 Доступные команды

- `npm run dev` - Запуск dev-сервера с горячей перезагрузкой
- `npm run build` - Сборка для production
- `npm start` - Запуск production сервера
- `npm run lint` - Проверка кода линтером
- `npm run typecheck` - Проверка TypeScript

## ✨ Функции приложения

✅ **Аутентификация** - Регистрация и вход через NextAuth  
✅ **Локализация** - Поддержка русского и английского языков  
✅ **Админ-панель** - Управление пользователями (нажмите V 5 раз)  
✅ **Плавные анимации** - Framer Motion для красивых переходов  
✅ **Dark theme** - Красивый тёмный дизайн с Tailwind CSS  
✅ **Responsive дизайн** - Адаптивный интерфейс для всех устройств
